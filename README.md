# LedgerLift Suite

Unified desktop app combining **CA Desk** (practice management for Chartered Accountants) and **Ledgify** (SME trader accounting) in a single Electron application.

## Features
- **CA Desk**: 15+ modules including Bank→Tally, GST reconciliation, Audit toolkit (CARO 2020, 3CD, MUS sampling), TDS & 26AS, Capital gains, Notice manager, MSME tracker, Fixed assets, Document vault
- **Ledgify**: Invoicing, Khata/clients, Inventory, Purchase, GST, Bank reconciliation, TDS/expenses, Reports, CA Connect
- **Unified user switcher**: One click to switch between CA mode and Trader mode
